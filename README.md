# 🎯 PathPilot India

**Your Personal AI Career Guidance Companion**

PathPilot India is an AI-powered career guidance platform designed to help students explore career opportunities, understand required skills, and discover suitable career paths.

## 🚀 Features

- Student Profile Registration
- Career Explorer
- Career Recommendations based on skills and subjects
- Skill Gap Analysis
- AI-powered Career Analysis using Google Gemini
- Personalised career guidance

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Google Gemini API

## ⚙️ Installation

1. Clone or download this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Create a `.env` file in the project folder and add your Gemini API key:

   `GEMINI_API_KEY=your_api_key_here`

4. Run the application:

   `python -m streamlit run main.py`

## 🎯 Project Goal

To make career exploration and personalised career guidance more accessible to students across India.
